## 问题处理记录

当前没有已收集的外部反馈，不预填虚构问题。收到后按以下字段记录，优先链接对应 Issue，避免复制私人内容：

| 字段 | 填写要求 |
| --- | --- |
| 问题编号 | 对应 Issue 或本地记录编号 |
| 场景与环境 | 使用位置、设备与浏览器 |
| 复现步骤 | 可重复的最短操作 |
| 状态 | 待复现／已复现／修复中／待验证／已验证／暂不处理 |
| 修复位置 | 提交或 PR 链接 |
| 验证结果 | 原场景复测、相关回归、日期 |

影响注册、数据保存、访问隔离的问题优先于纯视觉优化。无法复现时如实保留“待复现”，不先写“已解决”。
