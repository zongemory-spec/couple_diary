# 我们的恋爱日记 · 多情侣注册版

一个站点可以承载多个互相隔离的双人小屋。维护者部署一次，其他情侣打开网站即可使用，无需建数据库、配置邮箱授权码或改代码。

## 普通用户怎么用

1. 打开维护者提供的网站，点击“邮箱注册”，设置至少10位密码，在邮箱中确认注册。
2. 第一人登录，填写自己的称呼、另一半称呼和相恋日，创建小屋。可以先帮两人填好资料。
3. 填另一半的注册邮箱，生成邀请，复制链接发给对方；已配置发信服务时也会发送邀请提醒。
4. 第二人用受邀邮箱注册并验证，登录后会看到待确认邀请（换设备也可发现邀请），核对或补充两人资料，点击接受。
5. 两人绑定后使用同一个小屋；其他情侣的数据、照片和附件均不可见。

支持常见合法邮箱地址，程序不限定 Gmail。邮箱收件和网站访问是否通畅取决于提供商及网络，不能承诺所有地区均免网络限制。

## 已有功能

| 功能 | 行为 |
| --- | --- |
| 邮箱注册与密码找回 | Supabase Auth 邮箱确认、确认邮件重发、找回密码、退出 |
| 资料与邀请 | 一人预填两人信息、目标邮箱验证、7天邀请、撤销重发、接受后双人绑定 |
| 私密信箱 | 标题与正文、收信/寄信、已读状态、最近100封、发送幂等 |
| 想你小铺 | 自定义商品、零元心意下单、回复、收货/发货状态；可保存外部商品链接 |
| 心情与回忆 | 心情记录、回应、月度晴雨表、私密照片、回忆相册、心愿兑现 |
| 见面约定 | 日期范围、倒计时、当天提醒、延期确认、归档回忆、Word/PDF行程附件 |
| 邮件提醒 | 邀请、来信、订单/发货、心情、回忆、心愿、计划及更新；可关闭个人提醒 |
| 四季界面 | 原有四季背景、动态效果、手机布局与减少动画设置 |

小铺保留原项目的“0元心意订单”，没有接入微信/支付宝支付、真实扣款或物流接口。外部商品链接跳转购物平台，交易由平台完成。

## 维护者部署一次

完整步骤：[部署说明](docs/DEPLOY.md)。邮件分为“注册确认/找回密码”和“业务提醒”两条链路，见[邮件配置](docs/MAIL.md)。

1. 新建 Supabase 项目，完整运行 `database/install.sql`。
2. 开启邮箱注册和 **Confirm email**，配置 **自定义 SMTP**、正式网站 URL、允许的 Redirect URLs；密码最短长度设为10。**不能关闭邮箱验证**，否则受邀邮箱的身份校验失去意义。
3. 本地打开 `setup.html`，输入 Project URL 和 Publishable key，下载并覆盖 `site/config.js`。无需预创建两个用户或填写 UUID。
4. 安装 Python 3.12+ 和 Node.js 24+，运行：

```sh
npm ci --ignore-scripts
npm test
npm run build
```

5. 把 `dist/` 发布到 HTTPS 静态托管。可用 Cloudflare Pages 手动上传，或构建命令 `npm run build`、输出目录 `dist`。仓库可直接上传 GitHub，再从 Actions 下载构建产物。
6. 按邮件文档部署 `diary-mail` Edge Function、配置 QQ SMTP / Resend（Gmail可选）、启用每分钟队列任务。普通使用者无需提供发信账号。

Supabase 自带测试邮件不能代替面向其他用户的正式发信服务。按[官方自定义 SMTP 文档](https://supabase.com/docs/guides/auth/auth-smtp)配置后，陌生邮箱才能正常注册收信。

## 项目结构

`site/` 前端；`database/install.sql` 当前唯一安装入口；`supabase/functions/diary-mail/` 后台发信；`tools/` 构建和离线配置工具；`tests/` 本地 PostgreSQL 兼容数据库与接口测试。

## 隔离与边界

- 身份来自 Auth 认证用户与已确认邮箱；浏览器不能指定自己的角色或小屋。
- 每人最多一个小屋，每屋最多两个槽位。资料确认与绑定在数据库事务中完成。
- 记录以房间范围验证；修订号防覆盖，提交号防重复；沿用原有作者、订单和归档权限校验。
- 私有 Storage 按上传账号所属小屋授权，不是“登录即可看所有人的文件”。照片上限2MB，行程附件20MB。
- 邀请 token 是随机值，邀请表只保存散列；为了发邮件，原始 token 暂存于禁止客户端直接读取的邮件队列。只有受邀且已验证邮箱可取回自己的当前邀请。
- 邮件正文不携带日记正文、照片或信件内容。队列有租约、重试、限额；SMTP结果不明确时暂停自动重发。
- 此个人项目没有解除绑定/换伴侣/账号自助注销、支付、管理员运营台、自动备份恢复等功能。站点维护者具备后台管理权限，不能视为端到端加密。

## 原版已有数据

本版改变了数据库主键及成员关系，**不要覆盖旧库**。安装器检测到旧版单小屋结构会中止，保留旧数据。请先从旧版导出文字备份、另存照片附件，建立新项目使用；当前未提供自动导入旧记录的界面。旧站可以保留用于查看。

## 验证

`npm test` 对当前安装 SQL 运行数据库和权限验证，包含两对情侣隔离、邀请、信件、原有记录与邮件队列。测试使用合成账号，不向真实邮箱发信。真实服务验收步骤见 [联调清单](docs/CHECKS.md)。
