03 · 两个登录用户

接下来，只做这两件事

1. 下载初始化脚本，用记事本打开，全选复制到 Supabase 的 SQL Editor，点击 Run。脚本只在自己的全新项目使用。

2. 下载 config.js，放到自己 GitHub 仓库的 site/config.js，覆盖同名文件并提交。Cloudflare 连接仓库后会自动更新。

随后按 README 关闭公开注册与匿名登录，并连接 Cloudflare 部署。邮件提醒以后再设置也可以。

生成的私人SQL不用上传GitHub。config.js只有网站所需的公开连接配置与称呼，没有登录密码。
